# FractalLauncher

<a href="https://launcher.extremeteam.online">**Website**</a>

FractalLauncher is a free, open-source Minecraft launcher written in Python, made by YouTuber **TheExtreme_Ray**. It supports both Microsoft and offline (cracked) accounts, and was built to be a replacement for TL — everything it had, and more.

**Safety is the top priority.** Every feature is built from the consumer's point of view and refined until it's right.

## Features

- **Profiles** — isolated instances, each with its own version, loader and memory allocation
- **Accounts** — Microsoft and offline (cracked) accounts side by side, switching in one click
- **Skin manager** — upload any PNG skin and apply it to offline accounts through AuthLib, Classic or Slim model, with a live preview
- **Free capes** — built-in cape support for offline accounts, with a set of preset capes ready to equip
- **Mods, shaders and resource packs** — fetched directly from Modrinth, with search, one-click install, toggles and instant removal
- **Recommended servers** — a built-in list, so finding somewhere to play doesn't mean hunting IPs on forums
- **Screenshots and editor** — browse every capture, then crop, blur or draw over screenshots right inside the launcher
- **World backups** — snapshot your saves in one click before a big experiment
- **Diagnostics** — checks that your Java directory is set, that AuthLib is in place, that no installed mods are incompatible — plus your OS and allocated RAM
- **Console** — every launch and game log in one place, copy anything in a single click, and a kill-process button when a game hangs
- **Settings** — multiple languages, multiple themes, custom themes, custom fonts, Java directory settings and an about section

Note: skins and capes for offline accounts only apply in single-player, not on multiplayer servers.

## Developer Edition

The project is fully open source. The Developer Edition includes every single file — including the ones used to build the app into an .exe and an installer — so you can read it, audit it, fork it and build it yourself.

## FAQ

**Does it work with cracked accounts?**
Yes — offline accounts are first-class. You can set skins through AuthLib and equip free preset capes. One honest limitation: offline skins and capes only apply in single-player.

**Can I still use my Microsoft account?**
Yes. Microsoft and offline accounts live side by side in the accounts manager, and switching between them takes one click.

**Where do mods, shaders and resource packs come from?**
Directly from Modrinth, fetched inside the launcher. Search, install and manage everything from the same panel.

**How is it different from TL?**
FractalLauncher set out to be a replacement for TL — the features people relied on, plus more — developed openly, with the consumer's point of view driving every decision.

**Is it safe?**
Safety is the project's top priority, and because the entire thing is open source (Developer Edition included, build files and all), you can verify exactly what runs on your machine instead of taking anyone's word for it.

**The game is stuck — what do I do?**
Open the console and press the kill-process button to end it cleanly. If you're reporting a bug, every log line can be copied with one click.

**Which platforms does it run on?**
It's built and shipped for Windows, available as an executable or an installer. Since it's fully open source, you can also run it straight from source.
